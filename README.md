# Encontra signos
## Sobre o projeto
Uma página web capaz de encontrar o signo zodiacal de acordo com a data de nascimento do usuário e exibi-lá, junto com uma descrição. A estrutura do projeto foi feita por meio de 3 arquivos com extensão PHP que contém o topo das páginas, a página inicial e o resultado a ser obtido; um arquivo de estilização com extensão CSS e um arquivo XML com as informações dos signos.

No desenvolvimento foi utilizado o [XAMPP](https://www.apachefriends.org/download.html), um pacote com os principais servidores de código aberto do mercado, incluindo FTP, banco de dados MySQL e Apache com suporte as linguagens PHP e Perl. É um método que torna extremamente fácil para os desenvolvedores a criar um servidor web local para fins de teste.

## Como usar o XAMPP
Se quiser testar o projeto com o [XAMPP](https://www.apachefriends.org/download.html), após a sua instalação, adicione a pasta do projeto dentro do caminho xampp\htdocs\" e inicie o XAMPP com a conexão Apache. Para entrar e testar a página web, você pode simplesmente pesquisar por localhost e o nome do projeto, no caso, pesquisando por ```localhost/Encontra-signos``` no seu navegador.

Você também pode testar a conexão com o XAMPP ao pesquisar por ```localhost/dashboard/```, é um painel no localhost que serve para gerenciar e monitorar aplicações ou serviços que estão sendo executados no seu próprio computador.
